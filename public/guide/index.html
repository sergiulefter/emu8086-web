Getting started

Your first 8086 program, in the browser.

emu8086-web is a free Intel 8086 assembler, emulator and debugger. Write assembly, run it one instruction at a time, and watch the registers and memory change.

I built it to make the EMU8086-style workflow accessible from both Linux and MacOS, without installing Windows software, Wine or a virtual machine. It runs locally in your browser tab, with no account.

1. Compile a small COM program

Open the emulator in a modern desktop browser and replace the editor contents with this program:

org 100h

mov ax, 2
add ax, 3
ret

org 100h sets the origin used by a DOS COM program. mov puts 2 in the AX register, add adds 3, and the final ret returns control to DOS in this COM environment.

  1. Press emulate or F5. This assembles the source and loads the result into the debugger.
  2. Press single step or F8 once. AX becomes 0002.
  3. Step once more. AX becomes 0005. Register values are displayed in hexadecimal.
  4. Step through ret to finish. The return-to-operating-system message is expected.

If compilation fails, check the reported line and column. Start with the program above before adapting code from another assembler: not every x86 dialect describes the same executable format.

2. Watch what each instruction changes

The emulator window shows the CPU registers, flags, disassembly and memory. The original source window highlights the next instruction. Double-click a register or memory byte to open the extended value viewer.

Try step back after the add instruction in the first example. AX returns from 0005 to 0002. Step back restores the previous machine state, including memory changes and screen output.

The step-delay setting slows continuous execution so changes are easier to follow. You can also use breakpoints, the stack, variables and flags windows. The windows menu in the taskbar restores closed or minimized windows and can reset their layout.

3. Print a message using DOS

This COM program uses DOS interrupt INT 21h, service 09h, to print a dollar-terminated string:

org 100h

mov ah, 09h
lea dx, message
int 21h
ret

message db 'Hello from emu8086-web!', '$'

lea dx, message puts the address of the string in DX. Press emulate, then run. The emulator screen opens when the program writes text. The final $ marks the end of the string and is not printed. For programs that request keyboard input, click the emulator screen before typing.

The screen is an 80×25 text-mode display. You can also write character and colour bytes directly to video memory at B800:0000; it is not a graphics-mode canvas.

Compatibility and current limits

emu8086-web follows the EMU8086 4.08 workflow and supports EMU8086/MASM-style syntax for coursework programs. It is an independent implementation, not the original Windows application or a complete PC emulator.

Supported features include COM programs, BIN and boot images, common DOS and BIOS services, macros, LOCAL, and the bundled INCLUDE 'emu8086.inc'. Include files from your computer are not loaded through that directive.

EXE-style programs using constructs such as .model, .data and .code, graphics video modes, file and disk services, mouse services, and EMU8086 virtual devices are not supported. Check the support matrix and known differences before relying on a feature.

The layout is designed for laptop and desktop screens, ideally 1366×768 or larger. The application is designed for modern browsers on Linux, Windows, macOS and ChromeOS; Chrome and Firefox on Linux are the tested reference platforms. This guide is readable on phones, but the emulator's window-based workspace is intended for a keyboard and a larger screen.

Common questions

Do I need to install anything?

No. The hosted emulator needs JavaScript and a modern browser, with no plugins or account. Assembly and execution happen in the browser.

Can I open an existing assembly file?

Use open or drag an .asm file onto the editor. The emulator's Load button also accepts raw .com and .bin files. Opening a file does not upload it to a server.

Why does my program stop after running for a while?

Continuous runs have a default limit of five million instructions to prevent endless loops from locking up the page. The instruction limit is configurable in options.

Where can I find more examples?

Use the editor's examples menu for bundled programs and new for templates. The original EMU8086 reference material is available under documentation and tutorials, with its attribution. This guide describes emu8086-web specifically; the support matrix remains the reference for what this implementation supports.

Where can I report a problem?

Open an issue on GitHub with a minimal assembly program, the action that failed, and the result you expected. Include your browser and operating system.
