emu8086-web — Online 8086 Assembler, Emulator & Debugger

emu8086-web is a free, browser-based alternative to EMU8086, designed for students who want to write, run and debug Intel 8086 assembly programs without installing Windows software.

Inspired by the classic EMU8086 4.08 workflow, it provides a familiar desktop-style assembly editor and debugger, including register inspection, memory inspection, breakpoints, step-by-step execution and an 80×25 text-mode display. It runs EMU8086-style COM programs; the documentation lists the supported features and current limitations.

It works directly in modern desktop browsers, including Chrome and Firefox on Linux, without Wine or a virtual machine.
